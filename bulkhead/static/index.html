Every tool call your agent makes passes through Clocked before it acts:

  • Guard screens what the agent reads, and cuts only the injected sentences.
  • Inspect judges each shell command on its own.
  • Decide judges it against your task and anything suspicious read earlier.
  • Protect masks personal data coming in and rewrites what goes out.
  • Verify checks the agent's final report against the tool output it actually got.
